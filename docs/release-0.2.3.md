# 0.2.3 の配信

## 変更内容

タイムラインの日付セルと同日 Event 一覧の詳細ボタンを取り除いた。\
◆と一覧は選択操作を維持し、開いている詳細だけが未保存確認後に追従する。\
PROJECT 名列、左の EVENT と下部の詳細ボタン、Project の編集とアーカイブへの入口を残した。\
管理データ、計算と保存経路は変更していない。

新規テストは単独マーカーの詳細1件と同日一覧の詳細2件をそれぞれ検出して失敗した後、削除後に成功した。\
移動確認のキャンセル、破棄、保存失敗と再試行、別 Project で同じ UUID を使う場合の保存対象を確認した。\
移動の接続テストは既存の選択経路を使うため、実装を変えず初回から成功した。

隔離した実 VS Code 1.146.0 の Default Dark Modern と Default Light Modern で、3日、1週間、月のホバーとキーボード選択を確認した。\
狭い月表示と1週間表示の4画像を artifacts/timeline-selection に記録し、日付領域の詳細0件と残る Project、Event 操作を確認した。\
詳細パネルに隠れない1週間表示で、編集中の同日選択の取消と元の Task への保存を確認した。\
利用者の管理ファイルを使わず、一時サンプルだけを変更した。

README の5画像は同じ13px、倍率0、Dark Modern で再取得し、日付を合わせたサンプルと配布用文書を同期した。\
元の画像を拡縮せず、既存の切り取り条件と本文上の共通倍率を維持する。

公開状態は validated, public、版の状態は validated であり、拡張 ID と識別子は変わらない。\
