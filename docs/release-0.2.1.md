# 0.2.1の配信

## 公開前の確認

Marketplace公式の公開APIとChromeの管理画面で、Glitch-Sound.glitchboardは0.2.0が公開済みであることを確認した。\
拡張の識別子は1f5f7ff2-b364-4729-b6a8-53f56bf480e8、publisherはGlitch-Sound、nameはglitchboardであり、0.2.1も同じ識別で更新する。\
以前の0.2.0未公開の記録は、その時点の作業結果であり、今回の確認結果とは区別する。

新リポジトリのmainは開始時の5da671244907d735360c98834c19aacee6449467と一致した。\
既存のv0.2.0タグは8b676c0f4b2fdf0617c2042bb498370b8d1c96e1を指し、v0.2.1は存在しなかった。\
GitHubの更新権限と通常pushのdry-runが成功し、Chromeでは既存publisherのOwnerとして管理画面を確認した。\
既存のブランチとタグを上書きせず、通常のfast-forwardと新しいタグを使う。

公開済み0.2.0のVSIXは以前準備した配布物とSHA-256が一致し、アイコン2種も現行と完全一致した。\
license指定とLICENSEファイルは0.2.0にもなく、今回も同じ状態を維持した。\
警告を隠すオプションと新しい利用許諾は追加していない。
