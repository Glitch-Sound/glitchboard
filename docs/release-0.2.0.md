# 0.2.0 の配信準備と確認

## 同じ拡張としての更新

[Marketplace](https://marketplace.visualstudio.com/items?itemName=Glitch-Sound.glitchboard) の公開版は確認時点で0.1.5である。\
publisher は Glitch-Sound、name は glitchboard、拡張 ID は1f5f7ff2-b364-4729-b6a8-53f56bf480e8である。\
0.2.0 の VSIX も同じ publisher と name を使い、既存拡張の更新を対象とする。

旧管理元は [glitchboard-ex](https://github.com/Glitch-Sound/glitchboard-ex)、新管理元は [glitchboard](https://github.com/Glitch-Sound/glitchboard) である。\
新リポジトリの main は作業開始時にローカルの768fd58と一致し、更新権限と Git push の dry-run を確認した。\
旧リポジトリにはタグ、GitHub Release、配信ワークフローは確認できなかった。\
旧リポジトリと既存履歴の削除や書き換えは行わず、新リポジトリへ通常の fast-forward と v0.2.0 タグで反映する。

公開済み0.1.5の VSIX も取得して確認した。\
repository の metadata は既に新リポジトリの URL であり、今回は実際のコードと説明、画像参照を新リポジトリの版へ揃える。\
PNG と SVG のアイコンは公開済み VSIX、旧リポジトリ、現行ファイルが完全一致する。

## ライセンス

旧リポジトリと公開済み0.1.5の VSIX のどちらにも、LICENSE ファイルと manifest の license 指定はなかった。\
同等でよいという指定に従い、新しい OSS ライセンスや利用許諾文を追加していない。\
ライセンス不在の VSCE 警告は残し、警告を隠すオプションは使っていない。\
ライセンスを明記する場合の判断は、今後の権利者の判断事項として残る。

## 旧データと利用者への説明

README の先頭と CHANGELOG に、旧データの互換性と移行を提供しないこと、更新前のバックアップと新しい空の保存先を案内した。\
以前の設定先は更新後も参照されるため、読み込めた場合も互換性の保証ではないことを明記した。\
ワークスペースに残る旧設定がユーザー設定に優先する場合もあるため、設定の確認と解除を更新手順へ加えた。

追加した3テストでは、旧形式を模した有効と無効な YAML を読み込み、反復起動しても内容と更新日時、ファイル一覧が変わらないことを確認した。\
既存ファイルへの新規作成は拒否され、設定と旧ファイルが変わらない。\
読み込みは書き込みを行わず、新規作成は既存の wx による保護を使うため、これらのテストは最初から成功した。\
通常の編集と削除は対象の保存先へ反映するため、旧ファイルを直接編集せず、新しい保存先へ切り替える手順とした。\
利用者の実データは検査に使っていない。

## 公開画像と配布物

配布用 README は manifest の版から公開タグ v0.2.0 の HTTPS URL を生成する。\
表示用の5画像と原寸への5リンクを、同じ raw.githubusercontent.com の画像へ向けた。\
VSCE は HTML の画像 src を変換しても a の href を変換しないため、原寸リンクも生成段階で確定する。\
サンプルと CHANGELOG のリンクも同じタグの新リポジトリを参照する。

VSIX は21ファイルで、ID、0.2.0、README と CHANGELOG、5画像、アイコン、実行ファイルと元ファイルの一致を確認した。\
検証用 artifacts、管理データ、秘密情報用の設定は同梱していない。\
公開前に新タグの画像 URL を取得し、公開後は Marketplace の版、repository と表示を確認する。

## 検証結果

- 全体検査: lint、型検査、FSD、108ファイル301テスト、ビルド、正式仕様7件、トレース、文書検査が成功した。
- UI 検査: 実ビルドの既存9本が成功した。
- README: 移行非対応の案内を含む表示と実画面5枚、本文幅830pxと1100pxでの表示を確認した。
- 文書検査: 参照23件、画像10参照、CHANGELOG とサンプルの同期、公開タグの URL を確認した。
- 負例: 画像欠落、誤った倍率、古い配布用 README、不明なコマンド、左ペイン欠落、生成器が原寸リンク1件だけを相対リンクに残す場合の6件を拒否した。

原寸リンクの負例は、生成器と生成結果を同じ誤りへ変えた状態でも独立した検査が失敗しており、生成器自身を期待値に使うだけの検査にはしていない。\
今回の変更は文書、配信準備と既存動作のテストであり、製品のシナリオと動作を変えない直接変更として扱った。\
全体検査の構成とプロダクト検査の分離は維持し、文書検査と同期処理だけを更新した。

VSIX、ハッシュと検査ログは artifacts/release-v0.2.0 に残す。\
VSIX 自体は Git の対象外である。
