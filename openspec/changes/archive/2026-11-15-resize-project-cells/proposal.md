# 提案

## 目的

PROJECT 一覧で名前を見ながら寸法を直接変更したい利用者が、上部のスライダーへ移動せずセル端を操作できるようにする。

## 変更内容

- 列幅と行高のスライダーを廃止し、名前セルの右端を列幅、下端を全 Project 共通の行高の操作箇所とする。
- 見えるグリップ、キーボード、取消、初期化を設け、行選択、詳細と並べ替えを独立させる。
- 保存済み寸法を引き継ぎ、同じ VS Code プロファイルでタブを開き直しても確定値を使う。
- 既定幅280pxの変更を保持する。

## 対象外

- YAML の構造、ID、集計、左の EVENT 一覧のサイズ変更。
- 行ごとに異なる高さ、GitHub push と Marketplace 公開。
