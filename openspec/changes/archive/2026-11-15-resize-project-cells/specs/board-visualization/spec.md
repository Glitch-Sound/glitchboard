# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-040 - タイムライン寸法の調整

WHEN Project の名前セルの右端または下端を操作したとき、GlitchBoard は SHALL 右端で列幅、下端で全 Project 共通の行高を変更し、既存の寸法スライダーを表示しない。\
見える操作箇所でポインターとキーボードによる調整、初期化を提供し、選択、詳細、並べ替えと入力を変更しない。\
設定した最小最大と表示面の幅に収め、取消とポインター捕捉の喪失では操作前に戻し、解放後の移動では変更しない。\
画面縮小は保存幅を変更せず、空の一覧でも列幅を調整できる。\
既存の保存寸法を引き継ぎ、同じ VS Code プロファイルでの再表示と再起動でも確定値を保持し、保存失敗では理由を表示して現在の値と入力を保つ。

#### Scenario: REQ-040-S01 - 寸法の変更と再表示

- **GIVEN** Project が複数あり、保存済みの寸法がある。
- **WHEN** 列幅と行高を変更し、ボードを閉じて同じ VS Code プロファイルで再表示する。
- **THEN** 保存済みの値を引き継いで全行に確定値を使い、上部の Event 追加は存在しない。

#### Scenario: REQ-040-S02 - 境界と取消

- **GIVEN** 寸法の調整操作が使える。
- **WHEN** 上限外へ調整し、次の操作を取り消す。
- **THEN** 最小最大を超えず、取消では操作前へ戻り、画面縮小後も日付と Project の操作に到達できる。

#### Scenario: REQ-040-S08 - セル右端の列幅変更

- **GIVEN** 名前セルの右端に操作箇所が見え、追加や詳細の入力中である。
- **WHEN** セル右端をドラッグして離す。
- **THEN** 全 Project の列幅と日付の開始位置が新しい幅に揃い、選択、詳細と入力を保ち、並べ替えと編集の保存要求は送らない。

#### Scenario: REQ-040-S09 - セル下端の共通行高変更

- **GIVEN** Project が複数あり、名前セルの下端に操作箇所が見える。
- **WHEN** いずれかの名前セルの下端をドラッグする。
- **THEN** つかんだ境界がポインターへ追従し、全 Project の行高だけを共通に変更し、選択と並び順を保つ。

#### Scenario: REQ-040-S10 - 取消とポインターの終了

- **GIVEN** 列幅または行高をドラッグ中である。
- **WHEN** Esc、ポインター取消、または捕捉喪失が起きる。
- **THEN** 操作前の寸法へ戻り、解放後の移動と他のポインターでは変更しない。

#### Scenario: REQ-040-S11 - キーボードと初期化

- **GIVEN** 寸法の境界にキーボードフォーカスが見える。
- **WHEN** 境界で次の操作を行う。
- **THEN** 表の結果となり、他の境界の寸法は変更しない。

| 操作 | 結果 |
| --- | --- |
| 右端で左右キー | 列幅を設定した刻みで変更する |
| 下端で上下キー | 全 Project の行高を設定した刻みで変更する |
| Home またはダブルクリック | 対象の寸法を既定値に戻す |
| 調整中の Esc | 操作前の寸法に戻す |

#### Scenario: REQ-040-S12 - 狭い画面と空の一覧

- **GIVEN** 広い列幅を保存しているか、Project が未登録である。
- **WHEN** 狭い画面を表示してから広げる。
- **THEN** 日付と Project の操作領域に到達でき、広げると設定幅に戻り、Project がない場合も見出し右端で列幅を変更でき、寸法スライダーは存在しない。

#### Scenario: REQ-040-S13 - 表示設定の保存失敗と不正な値

- **GIVEN** 寸法を保存、復元する。
- **WHEN** 保存に失敗するか、不正な保存値がある。
- **THEN** 保存失敗では理由を表示して現在の寸法と入力を保持し、不正な値は既定値または設定した範囲へ収め、YAML は変更しない。
