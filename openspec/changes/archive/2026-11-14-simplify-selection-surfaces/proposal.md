# 提案

## 目的

ボードの利用者が選択した行を確認するとき、選択枠とキーボードフォーカスの枠が重なり、画面が煩雑に見える。\
最新の指定に合わせて選択の背景と枠を整理し、操作対象の識別と入力保護を維持する。

## 変更内容

- Event と Task の選択背景を維持し、選択枠をなくす。
- Story は選択によって背景を変えず、選択枠をなくす。
- 選択した詳細ボタンの強調と、キーボードフォーカスの識別を維持する。
- README の画像5枚を新 UI で撮り直し、表示条件と配布用の同期を維持する。

## 対象外

- Project の選択表示、選択操作、編集確認、保存モデルの変更。既存の動作を維持するためである。
- push と Marketplace 公開。今回の依頼に含まれない。

## 対象の仕様

### 新規

なし。

### 変更

- `board-visualization`: Story の選択時に背景と枠を変えない表示。
- `item-details`: Event と Task の選択枠をなくし、フォーカスと詳細ボタンの強調を保つ表示。

## 影響

- Webview の選択スタイル、両テーマのブラウザー回帰検査、前提文書を更新する。
- README の実画面と表示検証、配布用 README とローカル VSIX の同梱結果を更新する。
- API、YAML と設定の互換性への影響はない。

## 未決事項

なし。
