## MODIFIED Requirements

### Requirement: REQ-035 - レコードの選択と詳細
WHEN レコードをクリックまたはキーボードで選択したとき、GlitchBoard は紐づく下位情報を表示し、表示中の詳細を対象へ切り替えなければならない(SHALL)。\
Project、Event、Story、Task と左の Event に共通の詳細ボタンを置き、詳細が閉じている間は選択だけで開かず、詳細ボタンで開く。\
完了、ポイント、移動、削除などの独立操作は親の選択や詳細を発火させてはならない。\
Project 名と Task 名にホバー下線を出さず、Project の名前セル全体をポインターにし、設定色の選択左線を維持する。\
選択 Event は左の一覧、タイムラインと同日一覧、要約で判別でき、Project、Event、Task の詳細ボタンを選択前景で強調する。\
空の Project の選択確定では左右の Event 選択を解除し、キャンセルでは解除しない。\
Event と Task の選択背景を維持し、選択枠を表示してはならない。\
強調は確定した選択へ追従し、Story の選択操作、キーボードフォーカスの枠、危険表示と完了の取り消し線は維持する。

#### Scenario: REQ-035-S01 - 名前と独立した操作

- **GIVEN** Project、Event、Story、Task のレコードが見えている。
- **WHEN** 名前、行の余白または詳細ボタンを実行する。
- **THEN** 名前と余白はそのレコードを選択し、詳細ボタンは対象の詳細を開く。\
  Project はその Event、Event は Story、Story は Task の情報を示す。
- **AND** 詳細表示中の別レコード選択では対象が切り替わり、完了とポイントの操作では対象が変わらない。

#### Scenario: REQ-035-S02 - Project のセルと詳細の強調

- **GIVEN** ダークまたはライトの画面に複数の Project がある。
- **WHEN** 名前のセルをホバーし、クリックまたはキーボードで選択する。
- **THEN** 名前に下線を出さず、セル全体のポインターカーソル、選択中の設定色の左線、明るい選択前景の詳細ボタンを表示する。
- **AND** 未選択の詳細は補足の有無による色へ戻り、フォーカスを判別できる。

#### Scenario: REQ-035-S03 - Event の選択の強調

- **GIVEN** 複数の Event をダークまたはライトで表示している。
- **WHEN** Event の選択が確定する。
- **THEN** 次の各場所で選択と未選択を区別し、選択中の詳細ボタンを選択前景で強調する。

| 場所 | 選択の表示 |
| --- | --- |
| 左の EVENT 一覧 | 選択行全体 |
| タイムライン | 選択 Event を含むマーカーと同日一覧の対象行 |
| 下部の要約 | 表示中の Event |

- **AND** 選択背景を維持して選択枠を出さず、危険色とキーボードフォーカスの枠を維持し、編集中の移動をキャンセルした場合は元の選択表示を保持する。

#### Scenario: REQ-035-S04 - Task の選択の強調

- **GIVEN** 通常と完了の Task をダークまたはライトで表示している。
- **WHEN** Task 名をホバーし、クリックまたはキーボードで選択する。
- **THEN** ホバーの下線を出さず、選択中の詳細ボタンを選択前景で強調する。
- **AND** 選択背景を維持して選択枠を出さず、完了の取り消し線、キーボードフォーカスの枠、独立した完了とポイント操作を維持する。

#### Scenario: REQ-035-S05 - 空の Project の選択

- **GIVEN** Event を選択中で、Event がない Project がある。
- **WHEN** 空の Project を選択する。
- **THEN** 選択が確定した場合だけ左右の Event 選択を解除し、空の Project の左線と詳細ボタンだけを選択表示にする。
- **AND** 編集中の移動をキャンセルした場合は元の Event 選択と入力を保持し、管理ファイルと Project ファイルを変更しない。
