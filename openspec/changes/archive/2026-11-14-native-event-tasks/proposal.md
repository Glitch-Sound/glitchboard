# 提案

## 目的

利用者の追加指示に従い、旧版のデータ移行と互換性を設計の制約から外す。\
Event に Task を直接保存できる現在の要件を正とし、互換性のためだけの自動 Story と旧版の移行処理をなくす。

## 変更内容

- Event の tasks に Task を直接保存し、Story は利用者が必要時に作る任意グループとする。
- 直接 Task と Story 内 Task を表示、編集、完了、削除、子件数、進捗、残作業、負荷、実績ペースに等しく反映する。
- 旧データの自動移行処理と互換性の保証を除く。
- 旧リポジトリのアーカイブ、旧 schema と画面証跡を現行成果物から外す。
- タイムライン、負荷、初期設定、YAML 保存など、今回採用する機能は既存の検証済み部品を再利用する。

## 対象外

- 旧管理ファイルの移行、旧版への戻し互換性。
- 公開、push、Marketplace 登録、README への画面キャプチャ追加。

## 対象の仕様

### 新規

なし。

### 変更

- `data-management`: Event 直下の tasks と、読込時の非変更。
- `hierarchy-editing`: 自動 Story を作らない直接追加。
- `board-visualization`: 直接 Task と任意グループの初期表示。
- `item-details`: 旧リンク情報の自動移行を廃止する。

## 影響

旧データの互換性は提供範囲から外す。\
今回採用する計算式と UI 操作は維持し、対象 Task を新モデルへ広げる。\
旧コードを残す判断は互換性ではなく、責務分離と既存の検証が今回の要件に適合するためである。

## 未決事項

なし。
データは Project > Event > Task とし、Event > Story > Task を任意の整理方法として併用する。
