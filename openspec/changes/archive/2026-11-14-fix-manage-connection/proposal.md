# 提案

## 目的

ユーザー設定の共有と YAML の外部変更監視を仕様どおりにし、非読込ファイルの不在で接続全体を止めない。

## 変更内容

- 初期設定をユーザー設定へ保存する。
- yaml と yml の監視パターンと通知を検証する。
- 非読込ファイルの概要が取れなくても、他の正常な Project を配信する。

## 対象外

公開と push、README への画像追加、旧データ移行は行わない。

## 対象の仕様

### 新規

なし。

### 変更

vscode-integration、data-management。

## 影響

製品データの ID とファイル名は変更しない。

## 未決事項

なし。
