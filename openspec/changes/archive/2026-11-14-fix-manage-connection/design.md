# 設計

## 背景と制約

提案は proposal.md、前提は openspec/tech.md の 実行境界と保存モデルである。

## 設計判断

### D-01 - 参照と接続の明示

- 選択: 設定は Global に保存し、絶対パスの設定を machine スコープにする。
監視は **/*.{yaml,yml} を登録し、非読込概要の読込失敗はファイル名と利用不可の表示へ限定する。
- 理由: 作業フォルダや拡張子の違いで接続が変わらず、非読込項目の不在が正常な表示を妨げない。
- 代替案: Workspace だけへの保存と yaml だけの監視は仕様を満たさないため採用しない。
- 昇格: openspec/tech.md の 参照と接続
