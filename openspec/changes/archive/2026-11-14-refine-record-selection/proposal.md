# 提案

## 目的

Story の現在の選択表現を基準に、Project、Event、Task の選択先と詳細操作の関係を分かりやすくする。\
名前の下線によるリンクのような表現を減らし、確定した選択を画面へ反映する。

## 変更内容

- Project 名のホバー下線を外し、名前セルの余白もポインターカーソルとし、選択中の左線を維持する。
- Event の選択を左の一覧、タイムラインと同日一覧、下部の要約へ示す。
- Project、Event、Task の選択中の詳細ボタンを、Story と同様にテーマの選択前景で強調する。
- Task 名のホバー下線を外し、完了の取り消し線は維持する。

## 対象外

- Story の操作と見た目、行の選択と詳細の役割、編集中の保護は変更しない。
- データ形式、計算、push、公開と README の画面キャプチャ追加は扱わない。

## 対象の仕様

### 新規

なし

### 変更

- `item-details`: REQ-035 の選択表現と REQ-026 の選択時の詳細色を明記する。

## 影響

- DetailButton の選択表示、Timeline と EventList、EventDetails の選択状態、EventsApp の選択の受け渡しへ影響する。
- 既存の通信と入力保護を使い、未確定の選択を先に反映しない。

## 未決事項

なし
