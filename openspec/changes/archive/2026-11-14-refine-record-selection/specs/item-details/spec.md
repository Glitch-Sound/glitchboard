# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-026 - 詳細パネルの表示
WHEN どの階層の詳細ボタンを押したときも、GlitchBoardは SHALL 右側のパネルに種別と階層、主要指標3つ、補足、編集と削除を示す。\
未選択では補足があれば詳細ボタンを青、なければ灰色とし、補足なしでは「+ 補足を追加」を示す。\
Taskにはポイント、Projectには色の編集部品を示し、Escまたは×で閉じる。\
上部は対象 Project の名前と設定色を共通タイトルにし、その下に EVENT : 名前のような種別と対象名、階層を示し、主要指標は3枚のカードで示す。\
Taskのポイントは Task 一覧と同じ配色、バッジ、スライダー、数値と未見積の選択で編集し、「補足」は区切り線付きの見出しとする。\
下部の編集と削除は間隔を空けた独立ボタンにする。\
選択中の詳細ボタンの強調は REQ-035 に従う。

#### Scenario: REQ-026-S01 - 補足あり

- **GIVEN** noteを持つStoryがある。
- **WHEN** 青い詳細ボタンを押す。
- **THEN** 右側にStoryの詳細が開く。

#### Scenario: REQ-026-S02 - 補足なし

- **GIVEN** noteがないTaskがある。
- **WHEN** 灰色の詳細ボタンを押す。
- **THEN** + 補足を追加が表示される。

#### Scenario: REQ-026-S03 - 共通の所属表示とポイント

- **GIVEN** Project、Event、Story、Task が同じ Project に属している。
- **WHEN** 各詳細を表示する。
- **THEN** すべてで Project 名と設定色、対象種別と名前を表示し、Task のポイントは一覧と同じ操作と配色で変更できる。

#### Scenario: REQ-026-S04 - 明暗の設定色でも読める所属

- **GIVEN** Project 色が白、黒または淡色であり、ダークまたはライトの詳細を表示する。
- **WHEN** 所属 Project 名を表示する。
- **THEN** 設定色の枠をそのまま保ち、タイトル文字はテーマの前景へ寄せた設定色で表示して背景と区別できる。
- **AND** Project の保存色と他のマーカーの色は変更しない。

### Requirement: REQ-035 - レコードの選択と詳細
WHEN レコードをクリックまたはキーボードで選択したとき、GlitchBoard は紐づく下位情報を表示し、詳細が開いていればその対象へ切り替えなければならない(SHALL)。\
Project、Event、Story、Task と左の Event に共通の詳細ボタンを設け、詳細が閉じているときはレコード選択だけで開かず、詳細ボタンで開かなければならない。\
完了、ポイント、移動、削除などの独立した操作は親の選択や詳細操作を発火させてはならない。\
Project 名と Task 名のホバー下線を表示せず、Project の名前セル全体をポインターカーソルとし、選択中の左線は設定色を維持する。\
選択中の Event は左の一覧、タイムラインと同日一覧、下部の要約で判別でき、Project、Event、Task の詳細ボタンを選択前景で強調する。\
強調は確定した選択へ追従し、Story の選択操作と表現、フォーカス、危険表示と完了の取り消し線は維持する。

#### Scenario: REQ-035-S01 - 名前と独立した操作

- **GIVEN** Project、Event、Story、Task のレコードが見えている。
- **WHEN** 名前、行の余白または詳細ボタンを実行する。
- **THEN** 名前と余白はそのレコードを選択し、詳細ボタンは対象の詳細を開く。\
  Project はその Event、Event は Story、Story は Task の情報を示す。
- **AND** 詳細表示中の別レコード選択では対象が切り替わり、完了とポイントの操作では対象が変わらない。

#### Scenario: REQ-035-S02 - Project のセルと詳細の強調

- **GIVEN** ダークまたはライトの画面に複数の Project がある。
- **WHEN** 名前のセルをホバーし、クリックまたはキーボードで選択する。
- **THEN** 名前に下線を出さず、セル全体のポインターカーソル、選択中の設定色の左線、明るい選択前景の詳細ボタンを表示する。
- **AND** 未選択の詳細は補足の有無による色へ戻り、フォーカスを判別できる。

#### Scenario: REQ-035-S03 - Event の選択の強調

- **GIVEN** 複数の Event をダークまたはライトで表示している。
- **WHEN** Event の選択が確定する。
- **THEN** 次の各場所で選択と未選択を区別し、選択中の詳細ボタンを選択前景で強調する。

| 場所 | 選択の表示 |
| --- | --- |
| 左の EVENT 一覧 | 選択行全体 |
| タイムライン | 選択 Event を含むマーカーと同日一覧の対象行 |
| 下部の要約 | 表示中の Event |

- **AND** 危険色とフォーカスを維持し、編集中の移動をキャンセルした場合は元の選択表示を保持する。

#### Scenario: REQ-035-S04 - Task の選択の強調

- **GIVEN** 通常と完了の Task をダークまたはライトで表示している。
- **WHEN** Task 名をホバーし、クリックまたはキーボードで選択する。
- **THEN** ホバーの下線を出さず、選択中の詳細ボタンを選択前景で強調する。
- **AND** 完了の取り消し線、キーボードのフォーカス、独立した完了とポイント操作を維持する。
