# 差分仕様

## MODIFIED Requirements

### Requirement: NREQ-003 - テーマ追従

WHILE VS Codeのテーマが変わるとき、GlitchBoardは SHALL ダーク・ライトの両方で文字、Project色、ポイント色、危険色を判読可能に表示する。

検証用の Chromium で、通常サイズのポイント文字は背景とのコントラスト4.5:1以上とし、透過と祖先の背景を合成して判定する。\
対象は一覧と詳細のバッジ、選択肢と現在値、未見積であり、完了した項目も数値を薄くしない。\
検証の標準前景と背景はダーク #d4d4d4 / #181818、ライト #333333 / #ffffff とし、Project 色を白と黒、チャートの色を白、黒、灰色へ変更しても確認する。\
完了は一覧のチェックと名前の取り消し線、一覧と詳細のポイントの操作不可と点線枠で区別し、保存値は変更しない。

#### Scenario: NREQ-003-S01 - ライトテーマ

- **GIVEN** VS Codeのライトテーマを使用している。
- **WHEN** ボードを開く。
- **THEN** VS Codeテーマ変数を使った背景と文字になり危険の赤と21ptの赤紫を区別できる。

#### Scenario: NREQ-003-S02 - ポイントの通常表示

- **GIVEN** 検証用のダークまたはライトテーマで、全7値と未見積の Task を表示している。
- **WHEN** 一覧、詳細とポイント選択肢を開く。
- **THEN** 通常サイズのポイント文字は背景とのコントラスト4.5:1以上となり、既存の段階別の色を文字、背景と枠へ反映する。

#### Scenario: NREQ-003-S03 - 完了したポイント

- **GIVEN** 完了済みの Task が一覧と詳細にある。
- **WHEN** ポイントを表示する。
- **THEN** 数値のコントラストを4.5:1以上に保ち、一覧のチェックと名前の取り消し線、一覧と詳細の点線の枠と操作不可で完了状態を判別できる。
- **AND** 完了を解除すると編集可能へ戻る。

#### Scenario: NREQ-003-S04 - 配色変更

- **GIVEN** 検証用テーマで Project 色が白または黒、またはチャートの色が白、黒、灰色に変更されている。
- **WHEN** ポイントを通常と完了状態で表示する。
- **THEN** ポイント文字のコントラストを4.5:1以上に保ち、Project 色とポイントの保存値を書き換えない。
