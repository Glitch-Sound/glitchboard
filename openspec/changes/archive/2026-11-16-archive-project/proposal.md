# 提案

## 目的

利用者が終了した Project を削除せず、PROJECT 一覧から片付けられるようにする。

## 変更内容

- Project 詳細の編集にアーカイブのチェック欄を置き、保存成功後に PROJECT 一覧から非表示にする。
- Project YAML の任意の `archived` に状態を保存し、既存ファイルの省略は未アーカイブとして扱う。
- EVENT 一覧、選択中の Event、関連データと読み込み対象の集計を維持する。
- 取消、未保存の移動確認と保存失敗に既存の入力保護を適用する。

## 対象外

- アーカイブ済み Project の再表示、復元用 UI、旧版管理ファイルの移行。
- アーカイブによる読み込み設定の変更、関連データの削除、集計の除外。
- push と公開。

## 対象の仕様

### 新規

なし。

### 変更

- `item-details`: REQ-047 として Project のアーカイブ編集と永続化を追加する。

## 影響

- 共有スキーマ、編集メッセージ、Project YAML 保存、詳細の編集フォーム、タイムラインの Project 行を変更する。
- 読み込み時の書き換えは行わず、読み込み設定や Project のファイル参照を維持する。

## 未決事項

なし。
