# 提案

## 目的

Event がない Project の選択でメインの Event 表示が消えても、左では以前の Event を選択したままになる。\
新しい選択表現が実際の表示と矛盾しないよう、Event の選択解除を左右へ反映する。

## 変更内容

- 空の Project への選択が確定したら、メインと左の Event 選択を解除する。
- 既存の selectEvent メッセージで null を選択解除として扱い、既存の BoardSession の解除処理へつなぐ。
- 編集確認のキャンセルでは選択解除を送らず、元の選択と入力を保つ。

## 対象外

- Story の操作と見た目、保存形式、計算は変更しない。
- push、公開、README の画面キャプチャ追加は行わない。

## 対象の仕様

### 新規

なし

### 変更

- `item-details`: REQ-035 に空の Project の選択を定義する。

## 影響

- 操作メッセージの検証、BoardApp の選択確定と実画面の検査へ影響する。
- YAML は変更せず、既存のファイル選択と未保存保護を維持する。
