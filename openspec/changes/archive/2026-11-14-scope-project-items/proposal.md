# 提案

## 目的

同じ UUID が別 Project に存在すると最初の一致を操作してしまう誤更新を防ぐ。

## 変更内容

- 登録された Project ファイルと項目 ID を使って対象を特定し、曖昧または無効な操作は書き込まず拒否する。
- 選択、詳細、追加、編集、完了、削除、表示順と集計を同じ対象に対応付ける。

## 対象外

公開と push、README への画像追加、旧データ移行は行わない。

## 対象の仕様

### 新規

なし。

### 変更

data-management。

## 影響

製品データの ID とファイル名は変更しない。

## 未決事項

なし。
