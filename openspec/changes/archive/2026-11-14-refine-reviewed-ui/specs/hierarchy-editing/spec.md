# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-042 - Project 色の直接入力

WHEN Project の色を追加または詳細で指定するとき、GlitchBoard は SHALL 色ピッカーと同期する16進数入力を提供する。\
入力は # と6桁の16進数、大文字小文字と前後の空白を受け付け、保存時は # と小文字6桁へ正規化する。\
短縮3桁、透過付き8桁、色名、空欄と不正文字では理由を示し、保存要求を送らない。\
追加ではフォームの確定時、詳細のコード入力では色の保存または移動確認の保存時だけ反映し、既存ピッカーの詳細での即時保存は維持する。\
取消、保存失敗と移動のキャンセルで未保存内容を保護し、ダークとライトで入力、選択色とエラーを判別できる。

#### Scenario: REQ-042-S01 - 対応形式

- **GIVEN** Project のカラーコード欄がある。
- **WHEN** 次のコードを入力する。
- **THEN** 各入力を次の値として扱う。

| 入力 | 結果 |
| --- | --- |
| #12aBcD | #12abcd |
| 前後に空白のある #A0B1C2 | #a0b1c2 |
| #abc | 無効 |
| #11223344 | 無効 |
| red | 無効 |
| 空欄 | 無効 |
| #12gh56 | 無効 |

#### Scenario: REQ-042-S02 - 追加とピッカーの同期

- **GIVEN** Project 追加欄を開き、名前を入力している。
- **WHEN** コード #AaBbCc を入力して追加を確定する。
- **THEN** プレビューとピッカーは同じ色を示し、#aabbcc と名前を1回だけ追加する。
- **AND** ピッカーからの選び直しもコード欄へ反映し、取消した場合は追加しない。

#### Scenario: REQ-042-S03 - 無効な色の保存拒否

- **GIVEN** Project の追加または詳細に無効なカラーコードを入力している。
- **WHEN** 保存または追加を確定する。
- **THEN** 理由と無効な欄を示し、保存要求を送らず、入力したコードと名前を保持する。
- **AND** 有効なコードへ直せば同じ入力を保存できる。

#### Scenario: REQ-042-S04 - 詳細での確定と取消

- **GIVEN** Project の詳細で保存色が #123456 である。
- **WHEN** カラーコードを #AABBCC へ変更する。
- **THEN** 保存までは要求を送らず、「色を保存」または Enter で #aabbcc を保存する。
- **AND** 「色を取消」またはコード欄の Escape はコードだけを #123456 へ戻し、詳細と他の編集中の値を保持する。

#### Scenario: REQ-042-S05 - 詳細の移動と失敗

- **GIVEN** 詳細でカラーコードと名前または補足を変更している。
- **WHEN** 別レコードへの移動を要求する。
- **THEN** 保存、破棄、キャンセルを確認し、保存では変更した項目を同じ対象へまとめて保存する。
- **AND** 無効値、保存失敗とキャンセルでは移動せず、まだ保存していないコードと他の入力を保持する。

#### Scenario: REQ-042-S06 - 保存結果の再読込

- **GIVEN** コード入力で作成または更新した Project が YAML に保存されている。
- **WHEN** データを再読込する。
- **THEN** 同じ保存色をコード欄、Project マーカー、詳細の所属表示と左の Event に反映する。
- **AND** ダークとライトで入力文字と境界、フォーカス、無効値の理由を判別できる。

#### Scenario: REQ-042-S07 - 他の編集と確定したコードの正規化

- **GIVEN** 詳細で名前または補足と、前後の空白や大文字を含む有効なカラーコードを編集している。
- **WHEN** 詳細の保存を確定し、成功する。
- **THEN** コード欄も小文字6桁の保存値へそろえ、保存済みの色を未保存として扱わない。
- **AND** 保存失敗では正規化前の入力を保持する。
