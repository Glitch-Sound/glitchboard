# 提案

## 目的

両テーマの実ビルドを操作した結果、EVENT 行の崩れ、空の一覧の案内不足、通常文字に埋もれるエラー、淡い設定色のタイトルの読みにくさを確認した。\
画面の操作構造を保ったまま、読める一覧と一貫した状態表示へ直す。

## 変更内容

- 名前や補足と同時保存したコードも成功時に正規化し、未保存表示を残さない。
- 月表示の補助詳細ボタンをホバーとフォーカス時にセルの上へ表示し、期限マーカーとの重なりをなくす。
- 左の Event 名、補助情報、期限と詳細を現在のレコード構造に合わせ、危険な行を赤系で示す。
- 未登録、全 Project 非読込、Event なしと抽出結果なしで次の操作を案内する。
- 抽出条件を Escape と枠外で閉じられるようにする。
- 左右のエラーを共通の枠と警告アイコンで示し、長い理由も折り返す。
- 詳細タイトルは設定色を残しながらテーマの前景へ寄せ、淡色や暗色でも読めるようにする。

## 対象外

- 階層、保存形式、Taks、集計と既存の操作体系は変更しない。
- 新しいアイコン体系、依存更新と無関係なリファクタリングは行わない。
- push、公開、README の画面キャプチャ追加は行わない。

- `item-details`: REQ-026 の所属色とタイトルの可読性を両立する。

## 影響

- 共通の状態表示、左右の空状態、エラーとレコードの CSS に影響する。
- 実ビルドを両テーマで確認し、表示寸法とクリック経路も回帰検証する。
