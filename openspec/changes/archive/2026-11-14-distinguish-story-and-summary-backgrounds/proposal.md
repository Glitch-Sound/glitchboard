# 提案

## 目的

利用者が訂正した選択表示へ合わせ、左の Event 一覧と下部の Event 要約を区別し、Story の選択先を背景でも判別できるようにする。

## 変更内容

- メイン下部の Event 要約は選択によって背景を変えない。
- Story と直接 Task の Taks は選択中の行を他の選択行と同じ役割の明るい背景で示し、選択枠は付けない。
- Project、左の Event、Task とタイムラインの既存表示、選択操作、フォーカスと詳細の強調を維持する。
- 新 UI に合わせて README の実画面と配布物を更新する。

## 対象外

- 選択、保存、編集確認と YAML の変更。背景の役割だけを変更するためである。
- push と Marketplace 公開。

## 対象の仕様

### 新規

なし。

### 変更

- `board-visualization`: Story の選択背景。
- `item-details`: Event 要約の選択背景と他の場所の維持。

## 影響

- Webview の背景スタイル、両テーマの表示検査、前提文書。
- 実 VS Code の撮影、README の画像と表示、VSIX の同梱検証。
- 共有スキーマ、通信、保存データと設定の互換性に影響はない。

## 未決事項

なし。
